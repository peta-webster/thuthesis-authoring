# Output Contract

Every execution that creates or modifies thesis files should report:

- Modified files.
- Source material used.
- Chapter/section mapping.
- Validation checks run.
- TODO list.
- For generated projects, selected-main `submission_ready`, TODO counts, and whether graph traversal completed.
- Assumptions.
- Items requiring user review.
- Compile result or compile limitation.

Use concise summaries. Do not hide missing evidence or unverified claims.
