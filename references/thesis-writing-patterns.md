# Thesis Writing Patterns

Default language style is formal academic Chinese.

Prefer:

- "本文围绕...问题展开研究。"
- "针对...不足，本文提出..."
- "实验结果显示，在...条件下，所提方法..."
- "需要进一步补充...以支撑该结论。"

Avoid:

- Overclaiming: "完全解决", "显著优于所有方法", "首次证明" unless explicitly supported.
- Casual phrasing: "这个方法挺好", "跑了一下效果不错".
- Unsupported novelty: "首次", "领先", "最优" without evidence.

When rewriting, preserve the user's original technical meaning. If the input is fragmentary, create a conservative paragraph and add TODO markers for missing context.

When the thesis discipline is unclear, use neutral research language rather than domain-specific jargon.
