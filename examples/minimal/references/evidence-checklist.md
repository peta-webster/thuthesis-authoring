# 证据与引用自查清单

责任主体：ThuThesis Authoring 示例项目。年份：2026。类型：项目原创教学文档。

本文随《学位论文写作与自查指南》共同提供，采用仓库 MIT 许可证，不是外部发表的论文或学校规范。

1. 每个主要判断是否对应具体材料，是否说明适用条件？
2. 对照修改前后的文字，结论强度有没有超出原有证据？
3. 数值的来源、单位和计算方法是否明确？教学数值是否有清楚标记？
4. 变量是否在首次出现时定义，图表编号和正文引用是否对应？
5. 参考条目是否真实存在，作者、年份和标题是否来自已提供材料？
6. 尚未确认的信息是否保留具体待办，而不是填入推测？
7. 结构检查和实际编译是否分别记录，是否检查了本次生成的产物？

该清单帮助组织审阅，不计算论文质量分数，也不能单独证明学术结论成立或论文可以提交。
